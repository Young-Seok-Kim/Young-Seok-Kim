제조·유통·서비스 산업군의 다양한 모바일 시스템 구축을 담당해 온 6년 차 개발자입니다. 아키텍처 개선을 통한 앱 최적화와 자동화 파이프라인(CI/CD) 구축을 즐겨 하며, 다수의 프로덕트를 기획부터 구글 플레이 스토어 정식 출시까지 올라운드로 리드한 경험이 있습니다.

### 🛠️ 주력 기술 스택
* **Mobile:** Kotlin, Java, Flutter, Android SDK (CameraX, Maps)
* **Architecture:** MVVM, MVP, Clean Architecture, Riverpod
* **Backend & DB:** Spring Framework, MyBatis, MySQL, SQLite, AWS (EC2, RDS)
* **DevOps:** GitHub Actions, Git, SVN

* **드림소프트웨어 (재직 중)** - 무림페이퍼 모바일 앱 전환 UI 및 API 개발 (업무 속도 25% 개선)
  - 여천NCC / 한화비전 모바일 시스템 외주 인력 일정 및 기술 관리
  - GitHub Actions 기반 배포 자동화 프로세스 구축 (배포 시간 40% 단축)
